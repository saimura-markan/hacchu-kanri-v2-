お客様データはすべて日本国内（AWS東京リージョン）に保管されます。国外へのデータ移転は行いません。

認証・通信セキュリティ

  • SSL/TLS暗号化通信：すべての通信はHTTPS（TLS 1.2以上）で暗号化されています
  • Supabase Auth：業界標準のJWT（JSON Web Token）認証を採用
  • Row Level Security（RLS）：データベースレベルで、各ユーザーが自分のデータのみアクセスできるよう制御しています
  • セッション管理：ログイン状態はブラウザのローカルストレージで安全に管理されます

パスワードの安全な管理

パスワードの設定ルール
  • 8文字以上で設定してください
  • 英字（a〜z / A〜Z）と数字（0〜9）を両方含めてください
  • 他のサービスと同じパスワードの使い回しはお控えください
パスワードはbcryptにより一方向ハッシュ化して保存します。当社スタッフでもお客様のパスワードを知ることはできません。
パスワードを忘れた場合

ログイン画面の「パスワードをわすれた方はこちら」から、登録メールアドレスにリセットリンクをお送りします。リセットリンクは一定時間で失効しますので、速やかにご対応ください。
当社からパスワードをメール・電話でお伺いすることは絶対にありません。パスワードを求める連絡があった場合はご注意ください。

データの管理・保護

発注・案件データ Supabaseデータベース（PostgreSQL）に暗号化して保管
アップロード画像・PDF Supabase Storage（S3互換）にて管理。署名付きURLにより本人のみアクセス可能
チャットメッセージ 案件ごとにデータベースで管理。RLSにより関係者以外からは閲覧不可
アカウント情報 Supabase Authにて管理。パスワードはハッシュ化保存
バックアップ Supabaseの自動バックアップ機能により定期保全

お客様へのお願い・利用ルール

アカウントの管理
  • アカウントは本人のみご利用ください。他人への貸し出しはお控えください
  • パスワードは定期的に変更することをお勧めします
  • 共用PC・スマートフォンでのご利用後は必ずログアウトしてください
禁止事項
  • 本サービスへの不正アクセス・改ざん行為
  • 他のお客様の個人情報・案件情報への不正アクセス
  • システムへの過度な負荷をかける行為（スクレイピング等）
  • 虚偽の情報による発注・登録
禁止事項に違反した場合、アカウントの停止・法的措置を取る場合があります。
推奨ブラウザ・環境
  • Safari 最新版（iPhone / Mac）
  • Chrome 最新版（Android / PC）
  • Edge 最新版（Windows）
古いブラウザでは一部機能が正常に動作しない場合があります。最新バージョンへのアップデートをお勧めします。

不審なアクセス・問題発生時

以下のような状況にお気づきの際は、すぐにご連絡ください。

  • 身に覚えのないログイン通知が届いた
  • 登録していない発注データが表示されている
  • パスワードが勝手に変更されたようだ
  • 不審なメール・SMSが届いた（フィッシング疑い）
お客様のアカウントへの不正アクセスが疑われる場合、まずパスワードを変更し、当社まですみやかにご連絡ください。
