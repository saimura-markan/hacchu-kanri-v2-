## 画面遷移マップ

```
[ログイン画面]
  ├─→ [パスワードリセット画面]
  │      └─→ [新パスワード設定画面]
  ├─→ [新規登録画面]
  │
  ├─→ [注文履歴画面]（roleが user の場合）
  │      ├─→ [発注フォーム]
  │      ├─→ [注文詳細画面]
  │      │      └─→ [チャット画面]
  │      └─→ [マイページ]
  │
  └─→ [管理者画面]（roleが admin / manager / staff の場合）
         ├─→ [企業ID管理パネル]（adminのみ）
         ├─→ [スタッフ管理パネル]（admin/managerのみ）
         ├─→ [削除済み案件パネル]（adminのみ）
         ├─→ [チャット画面]（案件詳細から）
         └─→ [マイページ]
```

### ① ログイン画面（LoginApp）

**コンポーネント:** `LoginApp` → `LoginScreen`  
**行番号:** ~400〜870  
**ステータス:** ✅ 確認済み

**機能:**
| 機能 | ステータス |
|---|---|
| メール・パスワードでログイン（`sb.auth.signInWithPassword`） | ✅ 確認済み |
| ロール判定（admin/manager/staff → AdminApp、user → HistoryApp） | ✅ 確認済み |
| 企業の is_active チェック（無効企業はログイン拒否） | ✅ 確認済み |
| 「パスワードをお忘れの方」→ ForgotScreen遷移 | ✅ 確認済み |
| 「新規登録」→ RegisterApp遷移 | ✅ 確認済み |
| ページ下部に特徴説明（4列グリッド） | ✅ 確認済み |

**ロール判定ロジック:**
```
user_metadata.role === "admin" or "manager" → AdminApp
user_metadata.role === "staff"              → AdminApp（一部機能非表示）
それ以外（未設定含む）                      → HistoryApp
```
